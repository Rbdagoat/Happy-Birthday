How to add your own photos:
1. Make a folder named images in the same place as this HTML file.
2. Drop your photos in there and name them photo1.jpg, photo2.jpg, etc. (or any name — just update the src in the code to match).
3. Add or remove <div class="photo"> blocks to match how many photos you have.
4. Edit the caption text under each photo.
